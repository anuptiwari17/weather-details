# 🌤️ SkyStats

A weather forecast and visualization tool that displays real-time weather information and 5-day forecast data using the OpenWeatherMap API. It features interactive charts for temperature, humidity, pressure, and wind speed using Python data visualization libraries.

---

## 🔗 Live Project

👉 [Check out SkyStats](https://skystats.onrender.com/)

---

## 📌 Project Details

- **Tech Stack**: HTML, CSS, JavaScript, Python (Flask)
- **APIs Used**: OpenWeatherMap API
- **Libraries Used**:
  - `pandas` for data handling
  - `matplotlib` and `seaborn` for data visualization

---

## ✨ Features

- 🔍 User can enter any location to fetch weather data
- 🌤️ Shows current weather conditions (temperature, humidity, wind, pressure, etc.)
- 📅 Displays 5-day forecast in 3-hour intervals
- 📊 Interactive charts for:
  - Temperature trends
  - Wind speed
  - Humidity levels
  - Atmospheric pressure
